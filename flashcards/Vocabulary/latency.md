# latency

*What does this word mean and how is it used?*

## Verso

**latência**; atraso de resposta

_noun (uncountable)_

> The time it takes for a system to respond to a request.

### How to use

Use **latency** para falar do atraso entre um pedido e a resposta de um sistema, especialmente em APIs, redes e interfaces. Normalmente é medida em milissegundos.

### Example

We reduced API **latency** by caching frequent requests.

_Reduzimos a latência da API armazenando em cache as requisições frequentes._

### Common expressions

**low latency** — baixa latência; **latency spike** — pico de latência; **reduce latency** — reduzir a latência

### Word family

**latent** (adjective) — latente; **latency-sensitive** (adjective) — sensível à latência

### Related words and differences

**throughput** mede quantas operações um sistema processa; **latency** mede quanto tempo uma operação leva.
