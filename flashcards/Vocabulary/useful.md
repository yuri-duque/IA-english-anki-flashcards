# useful

## Dados da nota

- **WordFamily:** <b>usefulness</b> (utilidade); <b>usefully</b> (de maneira útil).
- **CommonExpressions:** <b>useful for</b> + noun/gerund (beneficial for a purpose); <b>useful to</b> + person (helpful to someone); <b>come in useful</b> (ser útil em uma situação).
- **RelatedWords:** <b>helpful</b> costuma descrever algo ou alguém que presta ajuda; <b>useful</b> destaca que algo tem utilidade ou serve a um propósito. A practical guide can be <b>useful</b>; a clear explanation can be <b>helpful</b>.

- **Word:** useful
- **Meaning:** <b>útil</b>; proveitoso, conveniente (conforme o contexto)
- **PartOfSpeech:** adjective
- **Definition:** Helping you do or achieve something; serving a practical purpose.
- **Example:** This guide is <b>useful</b> when you're setting up the router.
- **ExampleTranslation:** Este guia é <b>útil</b> quando você está configurando o roteador.
- **HowToUse:** Use <b>useful</b> para dizer que algo ajuda a alcançar um objetivo ou tem uma utilidade prática. É comum em <b>useful for</b> + substantivo/gerúndio e <b>useful to</b> + pessoa.
