# each
*What does this word mean and how is it used?*

## Verso
<span style="color:#2563eb"><b>cada</b></span>; cada um(a)

### Noun type
Usado com substantivo **contável no singular**:

- each student
- each book

### How to use
Use <span style="color:#2563eb"><b>each</b></span> para considerar os membros individualmente. Compare com `every`, que enfatiza o grupo ou a repetição.

### Quantity order
Não é uma posição fixa na escala: <span style="color:#2563eb"><b>each</b></span> distribui a atenção entre indivíduos.

### Examples
<span style="color:#2563eb"><b>Each</b></span> student received a book.

_Cada aluno recebeu um livro._

They received two tickets <span style="color:#2563eb"><b>each</b></span>.

_Eles receberam dois ingressos cada um._
