# same sort
*What does this phrase mean and how is it used?*

## Verso
**mesmo tipo**; mesma categoria; coisa parecida

### How to use
Geralmente aparece como **the same sort of + noun**, para dizer que coisas ou pessoas pertencem à mesma categoria.

### Example
They’re the **same sort of** people.

_Eles são o mesmo tipo de pessoas._

### Common expressions
**the same sort of thing** — o mesmo tipo de coisa
