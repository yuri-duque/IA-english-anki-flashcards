# regression

## Verso

**regressão**; falha em funcionalidade que antes funcionava

_noun_

> A problem that causes previously working software to stop working correctly.

### How to use

Use **regression** em testes e incidentes para um comportamento que piorou depois de uma mudança ou lançamento.

### Example

The release introduced a regression in the checkout flow.

_A versão introduziu uma regressão no fluxo de checkout._

### Common expressions

**regression test** — teste de regressão; **introduce a regression** — introduzir uma regressão; **regression suite** — suíte de regressão

### Word family

**regress** (verb) — regredir; **regressive** (adjective) — regressivo

### Related words and differences

**regression** é um problema novo causado por uma alteração; **incident** é um evento que afeta a operação e pode ter várias causas.
