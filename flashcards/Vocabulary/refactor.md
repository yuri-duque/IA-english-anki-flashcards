## Verso

**refatorar**; reorganizar código sem mudar seu comportamento externo

_verb_

> To improve code structure without changing its intended behavior.

### How to use

Use **refactor** para melhorar a legibilidade, o design ou a manutenção do código preservando o comportamento esperado.

### Example

We refactored the payment module before adding new rules.

_Refatoramos o módulo de pagamento antes de adicionar novas regras._

### Common expressions

**refactor code** — refatorar código; **incremental refactor** — refatoração incremental; **refactor safely** — refatorar com segurança

### Word family

**refactoring** (noun) — refatoração; **refactored** (adjective) — refatorado

### Related words and differences

**refactor** preserva o comportamento externo; **rewrite** substitui uma parte ou todo o código por uma implementação nova.
