# technical debt

*What does this word mean and how is it used?*

## Verso

**dívida técnica**; custo futuro causado por atalhos técnicos

_noun (uncountable)_

> The future cost created by choosing a quick or imperfect technical solution today.

### How to use

Use **technical debt** para explicar manutenção adicional, riscos ou lentidão futura causados por decisões técnicas de curto prazo.

### Example

We scheduled time to pay down technical debt in the authentication service.

_Reservamos tempo para reduzir a dívida técnica no serviço de autenticação._

### Common expressions

**accumulate technical debt** — acumular dívida técnica; **pay down technical debt** — reduzir dívida técnica; **technical-debt backlog** — backlog de dívida técnica

### Related words and differences

**technical debt** é uma metáfora para custos futuros de manutenção; **bug** é um defeito específico no comportamento do software.
