# deployment

*What does this word mean and how is it used?*

## Verso

**implantação**; publicação em produção

_noun_

> The process of making software available in an environment.

### How to use

Use **deployment** para o processo de colocar uma versão de software em produção ou em outro ambiente. É comum com **deploy** como verbo.

### Example

The deployment completed without downtime.

_A implantação foi concluída sem indisponibilidade._

### Common expressions

**production deployment** — implantação em produção; **deployment pipeline** — pipeline de implantação; **deployment strategy** — estratégia de implantação

### Word family

**deploy** (verb) — implantar; **deployed** (adjective) — implantado

### Related words and differences

**deployment** é o ato de publicar uma versão; **rollout** enfatiza sua liberação gradual para usuários.
