# enough
*What does this word mean and how is it used?*

## Verso
<span style="color:#2563eb"><b>suficiente</b></span>; o bastante; suficientes

### Noun type
Usado com contáveis no plural e incontáveis:

- enough chairs — cadeiras suficientes
- enough food — comida suficiente

### How to use
Use <span style="color:#2563eb"><b>enough</b></span> para dizer que há a quantidade necessária. Ele vem antes do substantivo: `enough money`; depois de adjetivos: `old enough`.

### Quantity order
<span style="color:#2563eb"><b>enough</b></span> não indica uma posição fixa: significa “tanto quanto necessário”.

### Examples
Do we have <span style="color:#2563eb"><b>enough</b></span> chairs for everyone?

_Temos cadeiras suficientes para todos?_

This room is big <span style="color:#2563eb"><b>enough</b></span> for the meeting.

_Esta sala é grande o suficiente para a reunião._
