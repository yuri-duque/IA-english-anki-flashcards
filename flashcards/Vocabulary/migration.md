# migration

*What does this word mean and how is it used?*

## Verso

**migração**; transferência para um novo sistema

_noun_

> The process of moving data, software, or systems to a new environment.

### How to use

Use **migration** para transferir dados, serviços, infraestrutura ou versões de tecnologia para um destino novo.

### Example

The database migration required a rollback plan.

_A migração do banco de dados exigiu um plano de reversão._

### Common expressions

**data migration** — migração de dados; **cloud migration** — migração para a nuvem; **migration plan** — plano de migração

### Word family

**migrate** (verb) — migrar; **migratory** (adjective) — migratório

### Related words and differences

**migration** move algo para um novo destino; **deployment** publica uma versão no ambiente-alvo.
