# root cause

*What does this word mean and how is it used?*

## Verso

**causa raiz**; origem fundamental de um problema

_noun phrase_

> The underlying reason why a problem happened.

### How to use

Use **root cause** ao explicar a razão fundamental de uma falha, indo além dos sintomas imediatos. É muito comum em análises pós-incidente.

### Example

The root cause was a configuration change that bypassed validation.

_A causa raiz foi uma alteração de configuração que ignorou a validação._

### Common expressions

**root cause analysis** — análise de causa raiz; **identify the root cause** — identificar a causa raiz; **root-cause investigation** — investigação de causa raiz

### Related words and differences

**root cause** é a origem fundamental; **symptom** é o efeito visível do problema.
