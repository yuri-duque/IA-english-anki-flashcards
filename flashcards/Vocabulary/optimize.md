# optimize

*What does this word mean and how is it used?*

## Verso

**otimizar**; melhorar a eficiência

_verb_

> To make something as effective or efficient as possible.

### How to use

Use **optimize** ao melhorar desempenho, custo, consumo de recursos ou fluxo de trabalho. Em inglês britânico, **optimise** é a grafia equivalente.

### Example

We optimized the query to reduce database reads.

_Otimizamos a consulta para reduzir leituras no banco de dados._

### Common expressions

**optimize performance** — otimizar o desempenho; **optimize for cost** — otimizar para custo; **optimize a query** — otimizar uma consulta

### Word family

**optimization** (noun) — otimização; **optimal** (adjective) — ideal

### Related words and differences

**optimize** melhora algo dentro de uma meta; **refactor** melhora a estrutura do código sem necessariamente visar desempenho.
