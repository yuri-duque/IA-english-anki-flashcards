# embarrassing
*What does this word mean and how is it used?*

## Verso
**constrangedor**; embaraçoso; humilhante

_adjective_

> Making someone feel ashamed, awkward, or uncomfortable.

### How to use
Use <b>embarrassing</b> para descrever algo que causa vergonha, constrangimento ou desconforto. Para descrever a pessoa que sente isso, use <b>embarrassed</b>.

### Example
That was an <b>embarrassing</b> mistake.

_Esse foi um erro constrangedor._

### Common expressions
<b>embarrassing situation</b> — situação constrangedora  
<b>embarrassing moment</b> — momento constrangedor
