# every
*What does this word mean and how is it used?*

## Verso
<span style="color:#2563eb"><b>todo</b></span>; toda; cada

### Noun type
Usado com substantivo **contável no singular**:

- every student
- every day

### How to use
Use <span style="color:#2563eb"><b>every</b></span> para falar do grupo inteiro de forma geral ou de uma ação repetida. Compare com `each`, que destaca os indivíduos separadamente.

### Quantity order
Não é uma posição fixa na escala: <span style="color:#2563eb"><b>every</b></span> inclui todos os membros ou ocorrências.

### Examples
I study English <span style="color:#2563eb"><b>every</b></span> day.

_Eu estudo inglês todos os dias._

<span style="color:#2563eb"><b>Every</b></span> student must sign the form.

_Todo aluno deve assinar o formulário._
