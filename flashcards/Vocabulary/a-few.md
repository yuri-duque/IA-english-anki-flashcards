# a few

## Verso
<span style="color:#2563eb"><b>alguns</b></span>; algumas; alguns poucos

### Noun type
Usado somente com substantivos **contáveis no plural**:

- a few questions
- a few friends

### How to use
Use <span style="color:#2563eb"><b>a few</b></span> para uma pequena quantidade suficiente. Compare com `few`, que tem sentido negativo e significa “quase nenhum”.

### Quantity order
all → most → a lot of / lots of → many → several → some → <span style="color:#2563eb"><b>a few</b></span> → few → no

### Examples
I have <span style="color:#2563eb"><b>a few</b></span> questions.

_Tenho algumas perguntas._

We need <span style="color:#2563eb"><b>a few</b></span> more chairs.

_Precisamos de mais algumas cadeiras._

### Related words and differences

- **few** — “quase nenhum”: **few questions**. **A few questions** significa “algumas perguntas” e soa mais positivo.
- **some** — “alguns”, sem destacar que a quantidade é pequena: **some questions**.
- **several** — “vários”, geralmente mais que **a few**: **several questions**.
- **a little** — “um pouco de”, mas usado com substantivos incontáveis: **a little water**. **A few** é usado com contáveis no plural: **a few bottles**.
