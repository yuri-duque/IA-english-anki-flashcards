# no
*What does this word mean and how is it used?*

## Verso
<span style="color:#2563eb"><b>nenhum</b></span>; nenhuma; zero

### Noun type
Usado com contáveis no plural e incontáveis:

- no students — nenhum aluno
- no milk — nenhum leite

### How to use
Use <span style="color:#2563eb"><b>no</b></span> diretamente antes do substantivo. A frase já fica negativa, então não use `not` com o mesmo verbo.

### Quantity order
all → most → a lot of / lots of → many / much → several / some → a few / a little → few / little → <span style="color:#2563eb"><b>no</b></span>

### Examples
<span style="color:#2563eb"><b>No</b></span> students came to class.

_Nenhum aluno veio à aula._

There is <span style="color:#2563eb"><b>no</b></span> milk in the fridge.

_Não há leite na geladeira._
