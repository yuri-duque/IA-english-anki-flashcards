# too much
*What does this phrase mean and how is it used?*

## Verso
<span style="color:#2563eb"><b>demais</b></span>; muita quantidade de

### Noun type
Usado somente com substantivos **incontáveis**:

- too much sugar
- too much noise

### How to use
Use <span style="color:#2563eb"><b>too much</b></span> quando a quantidade ultrapassar o limite desejável ou necessário.

### Quantity order
Não é uma posição fixa na escala: <span style="color:#2563eb"><b>too much</b></span> indica excesso de uma substância ou quantidade incontável.

### Examples
You are using <span style="color:#2563eb"><b>too much</b></span> sugar.

_Você está usando açúcar demais._

There is <span style="color:#2563eb"><b>too much</b></span> noise outside.

_Há barulho demais lá fora._
