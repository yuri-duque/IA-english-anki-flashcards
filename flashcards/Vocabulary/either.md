# either
*What does this word mean and how is it used?*

## Verso
<span style="color:#2563eb"><b>ou... ou</b></span>; qualquer um dos dois; também não

### Noun type
Como determinante, é usado com substantivos **contáveis no singular**, quando há duas opções:

- either answer
- either option

### How to use
Use <span style="color:#2563eb"><b>either</b></span> para escolher uma de duas opções. Use `either...or` para apresentar alternativas e `either` no final de uma frase negativa para significar “também não”.

### Quantity order
Não é uma posição fixa na escala: <span style="color:#2563eb"><b>either</b></span> indica uma de exatamente duas opções.

### Example
You can choose <span style="color:#2563eb"><b>either</b></span> option.

_Você pode escolher qualquer uma das duas opções._

### Common expressions
**either...or** — ou... ou  
**not... either** — também não
