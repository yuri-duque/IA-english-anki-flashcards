# either
*What does this word mean and how is it used?*

## Verso
<span style="color:#2563eb"><b>qualquer um dos dois</b></span>; ou... ou; também não

### Definition
Used to refer to one of two options; in negative sentences, it can mean “too.”

### Part of speech
Determiner, pronoun, adverb

### How to use
Use <span style="color:#2563eb"><b>either</b></span> como determinante antes de um substantivo contável no singular, ou como pronome, para indicar uma de duas opções. Use <span style="color:#2563eb"><b>either...or</b></span> para apresentar alternativas. No fim de uma frase negativa, <span style="color:#2563eb"><b>either</b></span> significa “também não”.

### Noun type
Como determinante, é usado com substantivos **contáveis no singular**, quando há duas opções:

- <span style="color:#2563eb"><b>either</b></span> answer
- <span style="color:#2563eb"><b>either</b></span> option

### Quantity order
Não é uma posição fixa na escala: <span style="color:#2563eb"><b>either</b></span> indica uma de exatamente duas opções.

### Example
You can choose <span style="color:#2563eb"><b>either</b></span> option.

_Você pode escolher qualquer uma das duas opções._

### Common expressions
<span style="color:#2563eb"><b>either...or</b></span> — ou... ou  
<span style="color:#2563eb"><b>not... either</b></span> — também não

### Related words and differences
<span style="color:#2563eb"><b>neither</b></span> means “nenhum dos dois”; <span style="color:#2563eb"><b>either</b></span> refers to one of the two options.
