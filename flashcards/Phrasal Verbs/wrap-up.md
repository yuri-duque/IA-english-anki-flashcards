# wrap up

## Dados da nota

- **PhrasalVerb:** `wrap up`
- **Translation:** concluir; encerrar; finalizar; resumir
- **AudioSource:** https://en.wiktionary.org/wiki/wrap_up (áudio: variante australiana)
- **Verb:** `wrap`
- **Particle:** `up`
- **HowToUse:** **Wrap up** é usado para concluir uma tarefa, encerrar uma reunião ou apresentação, ou resumir os pontos principais. Pode ser transitivo ou intransitivo.
- **Pattern:** **wrap up something** / **wrap something up**; **wrap up**
- **Separable:** Sim, quando há objeto. Com pronome, ele fica entre o verbo e a partícula: **wrap it up**.
- **Example:** Let’s **wrap up** the meeting before lunch.
- **ExampleTranslation:** Vamos encerrar a reunião antes do almoço.
- **AlternativeExamples:** I need to **wrap up** this report today. — Preciso finalizar este relatório hoje. Can you **wrap it up** in two minutes? — Você pode concluir isso em dois minutos?
- **Synonyms:** `finish up`; `conclude`; `summarize`
- **CommonExpressions:** **wrap up a meeting** — encerrar uma reunião; **wrap up a project** — concluir um projeto; **wrap up the discussion** — encerrar a discussão
- **Source:** https://en.wiktionary.org/wiki/wrap_up
