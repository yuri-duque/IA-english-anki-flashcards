# every — Production 2
## Dados da nota
- **Prompt:** Num aviso da escola, como dizer “Todo aluno deve assinar o formulário”?
- **Context:** A regra se aplica a cada membro da categoria em geral.
- **Answer:** <b>Every</b> student must sign the form.
- **PossibleAnswers:** Each student must sign the form.
- **Focus:** every
- **HowToUse:** Use <b>every</b> + substantivo singular para generalizar sobre todos os membros de um grupo.
- **Example:** <b>Every</b> visitor must show identification.
- **ExampleTranslation:** Todo visitante deve mostrar identificação.
- **CommonMistakes:** Não diga “every students”: o substantivo depois de <b>every</b> é singular.
- **Source:** flashcards/Vocabulary/every.md
