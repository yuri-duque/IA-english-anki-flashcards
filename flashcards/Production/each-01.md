# each — Production 1
## Dados da nota
- **Prompt:** Na distribuição de materiais, como dizer “Cada funcionário recebeu um crachá”?
- **Context:** Considere os funcionários individualmente.
- **Answer:** <b>Each</b> employee received a badge.
- **PossibleAnswers:** Every employee received a badge.
- **Focus:** each
- **HowToUse:** Use <b>each</b> antes de substantivo contável singular para destacar os membros um por um.
- **Example:** <b>Each</b> package has a tracking number.
- **ExampleTranslation:** Cada pacote tem um número de rastreamento.
- **CommonMistakes:** Depois de <b>each</b>, use singular: <b>each employee</b>, não “each employees”.
- **Source:** flashcards/Vocabulary/each.md
