# each — Production 3
## Dados da nota
- **Prompt:** Falando de um grupo específico de crianças, como dizer “Cada uma delas ganhou um prêmio”?
- **Context:** Use <b>each of</b> com o pronome plural que retoma o grupo.
- **Answer:** <b>Each of</b> them won a prize.
- **PossibleAnswers:** <b>Each of</b> the children won a prize.
- **Focus:** each of
- **HowToUse:** Use <b>each of</b> antes de pronome plural, artigo + nome plural ou possessivo.
- **Example:** <b>Each of</b> us has a different role.
- **ExampleTranslation:** Cada um de nós tem uma função diferente.
- **CommonMistakes:** Depois de <b>each of</b>, use pronome ou nome plural; o verbo principal costuma ficar no singular.
- **Source:** flashcards/Vocabulary/each.md
