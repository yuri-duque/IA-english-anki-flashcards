# each — Production 2
## Dados da nota
- **Prompt:** Ao dividir os ingressos igualmente, como dizer “Eles receberam dois ingressos cada um”?
- **Context:** <b>Each</b> vem depois da quantidade para marcar a distribuição individual.
- **Answer:** They received two tickets <b>each</b>.
- **PossibleAnswers:** <b>Each</b> of them received two tickets.
- **Focus:** each
- **HowToUse:** Coloque <b>each</b> depois de uma quantidade para dizer que ela vale para cada pessoa ou item.
- **Example:** The notebooks cost five dollars <b>each</b>.
- **ExampleTranslation:** Os cadernos custam cinco dólares cada um.
- **CommonMistakes:** Nesta posição, diga <b>two tickets each</b>; não coloque <b>each</b> antes da quantidade.
- **Source:** flashcards/Vocabulary/each.md
