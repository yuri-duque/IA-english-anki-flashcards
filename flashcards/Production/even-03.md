# even — Production 3

## Dados da nota
- **Prompt:** Como dizer: “Mesmo se chover, vamos sair”?
- **Context:** A condição é possível, mas não mudará a decisão.
- **Answer:** <b>Even if</b> it rains, we will go out.
- **PossibleAnswers:** We will go out <b>even if</b> it rains.
- **Focus:** even if
- **HowToUse:** Use <b>even if</b> para uma condição hipotética ou futura que não altera o resultado.
- **Example:** I'll help you <b>even if</b> it takes all day.
- **ExampleTranslation:** Vou ajudar você mesmo que leve o dia todo.
- **CommonMistakes:** Use <b>even if</b> para hipótese; <b>even though</b> introduz um fato real.
