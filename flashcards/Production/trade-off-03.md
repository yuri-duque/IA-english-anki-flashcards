# trade-off — Production 3

## Dados da nota

- **Prompt:** Pergunte qual é a principal compensação desta proposta.
- **Context:** Avaliação de alternativas antes de uma decisão.
- **Answer:** What is the main <b>trade-off</b> in this proposal?
- **PossibleAnswers:** What do we give up with this option?
- **Focus:** trade-off
- **HowToUse:** Use <b>main trade-off</b> para pedir uma síntese clara dos ganhos e perdas de uma opção.
- **Example:** The main <b>trade-off</b> is higher cost for lower latency.
- **ExampleTranslation:** A principal compensação é custo maior por menor latência.
- **CommonMistakes:** Não confunda <b>trade-off</b> com <b>trade</b>, que é troca comercial ou negociação.
