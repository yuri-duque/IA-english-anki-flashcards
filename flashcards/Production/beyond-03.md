# beyond — Production 3

## Dados da nota
- **Prompt:** Complete: “O problema é impossível de consertar.”
- **Context:** Use uma expressão fixa para dizer que algo não tem reparo.
- **Answer:** The problem is <b>beyond repair</b>.
- **PossibleAnswers:** It is <b>beyond repair</b>.
- **Focus:** beyond repair
- **HowToUse:** <b>Beyond repair</b> significa tão danificado que não pode ser consertado.
- **Example:** The old machine was <b>beyond repair</b>.
- **ExampleTranslation:** A máquina velha não tinha conserto.
- **CommonMistakes:** Não use <b>out of repair</b>; a expressão natural é <b>beyond repair</b>.
