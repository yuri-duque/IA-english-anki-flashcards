# which — Production 2

## Dados da nota
- **Prompt:** Diga em inglês: “Qual deles é o seu?”
- **Context:** O substantivo já está implícito; escolha uma opção entre várias.
- **Answer:** <b>Which one</b> is yours?
- **PossibleAnswers:** <b>Which</b> is yours?
- **Focus:** which one
- **HowToUse:** Use <b>which one</b> quando o objeto escolhido estiver implícito ou já tiver sido mencionado.
- **Example:** <b>Which one</b> would you like?
- **ExampleTranslation:** Qual deles você gostaria?
- **CommonMistakes:** Não diga “which one is it one”; <b>which one</b> já substitui o substantivo.
- **Source:** flashcards/Vocabulary/which.md
