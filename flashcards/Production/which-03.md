# which — Production 3

## Dados da nota
- **Prompt:** Complete: “O relatório, que foi publicado ontem, gerou debate.”
- **Context:** Use uma oração relativa para acrescentar informação sobre uma coisa.
- **Answer:** The report, <b>which</b> was published yesterday, sparked debate.
- **PossibleAnswers:** The report that was published yesterday sparked debate.
- **Focus:** which
- **HowToUse:** Use <b>which</b> para retomar uma coisa ou situação em uma oração relativa, especialmente após vírgula.
- **Example:** She missed the train, <b>which</b> caused a delay.
- **ExampleTranslation:** Ela perdeu o trem, o que causou um atraso.
- **CommonMistakes:** Em uma oração relativa não restritiva, mantenha as vírgulas ao redor de <b>which</b>.
