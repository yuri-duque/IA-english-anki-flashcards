# despite — Production 1

## Dados da nota
- **Prompt:** Como dizer: “Apesar da chuva, fomos caminhar”?
- **Context:** Você contrasta uma condição difícil com o resultado.
- **Answer:** <b>Despite</b> the rain, we went for a walk.
- **PossibleAnswers:** We went for a walk <b>despite</b> the rain.
- **Focus:** despite
- **HowToUse:** Use <b>despite</b> antes de substantivo, pronome ou verbo terminado em -ing.
- **Example:** She kept working <b>despite</b> feeling tired.
- **ExampleTranslation:** Ela continuou trabalhando apesar de se sentir cansada.
- **CommonMistakes:** Não use <b>despite</b> diretamente antes de uma oração completa; use <b>despite the fact that</b>.
- **Source:** flashcards/Vocabulary/despite.md

We went for a walk **despite** the rain.

#### Focus
**despite**

#### How to use
Use **despite** antes de substantivo, pronome ou verbo terminado em -ing.

#### Example
She kept working **despite** feeling tired.

_Ela continuou trabalhando apesar de se sentir cansada._

#### Common mistakes
Não use **despite** diretamente antes de uma oração completa; use **despite the fact that**.
