# might — Production 1

## Dados da nota

- **Prompt:** Como dizer: “Pode ser que chova mais tarde”?
- **Context:** Você fala de uma previsão incerta para esta tarde.
- **Answer:** It <b>might</b> rain later.
- **PossibleAnswers:** It <b>might</b> rain this afternoon.
- **Focus:** might
- **HowToUse:** Use <b>might</b> + verbo na forma base para expressar uma possibilidade incerta.
- **Example:** We <b>might</b> leave early tomorrow.
- **ExampleTranslation:** Talvez saiamos cedo amanhã.
- **CommonMistakes:** Não use <b>might to rain</b>; depois de <b>might</b>, use o verbo sem <b>to</b>.
- **Source:** flashcards/Vocabulary/might.md
