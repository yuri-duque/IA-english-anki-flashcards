# although — Production 1

## Dados da nota

- **Prompt:** Como dizer: “Embora estivesse chovendo, fomos caminhar”?
- **Context:** Você contrasta a chuva com a decisão de caminhar.
- **Answer:** <b>Although</b> it was raining, we went for a walk.
- **PossibleAnswers:** We went for a walk <b>although</b> it was raining.
- **Focus:** although
- **HowToUse:** Use <b>although</b> antes de uma oração completa para introduzir contraste.
- **Example:** <b>Although</b> he was tired, he finished the report.
- **ExampleTranslation:** Embora estivesse cansado, ele terminou o relatório.
- **CommonMistakes:** Não use <b>although ... but</b> na mesma frase.

## Verso

### Answer

**Although** it was raining, we went for a walk.

#### Other natural answers

We went for a walk **although** it was raining.

#### Focus

**although**

#### How to use

Use **although** antes de uma oração completa para introduzir contraste.

#### Example

**Although** he was tired, he finished the report.

_Embora estivesse cansado, ele terminou o relatório._

#### Common mistakes

Não use **although ... but** na mesma frase.
