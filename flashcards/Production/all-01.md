# all — Production 1
## Dados da nota
- **Prompt:** Numa reunião, nenhum participante faltou: como dizer “Todos os participantes chegaram”?
- **Context:** Fale do grupo inteiro usando um substantivo plural.
- **Answer:** <b>All</b> the participants arrived.
- **PossibleAnswers:** <b>All</b> participants arrived.
- **Focus:** all
- **HowToUse:** Use <b>all</b> + substantivo plural para incluir cada membro de um grupo.
- **Example:** <b>All</b> the lights were on when we arrived.
- **ExampleTranslation:** Todas as luzes estavam acesas quando chegamos.
- **CommonMistakes:** Com grupo específico, diga <b>all the participants</b>, não “all participant”.
