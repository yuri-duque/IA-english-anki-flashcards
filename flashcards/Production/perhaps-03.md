# perhaps — Production 3

## Dados da nota

- **Prompt:** Como responder “Talvez não” quando alguém pergunta se o restaurante estará aberto?
- **Context:** Você acha que há uma chance de ele estar fechado.
- **Answer:** <b>Perhaps not</b>.
- **PossibleAnswers:** <b>Perhaps</b> it won't be open.
- **Focus:** perhaps not
- **HowToUse:** Use <b>perhaps not</b> como resposta curta quando algo possivelmente não é verdade.
- **Example:** Will they agree? <b>Perhaps not</b>.
- **ExampleTranslation:** Eles vão concordar? Talvez não.
- **CommonMistakes:** Não diga <b>perhaps no</b> para negar uma possibilidade; use <b>perhaps not</b>.
- **Source:** flashcards/Vocabulary/perhaps.md
