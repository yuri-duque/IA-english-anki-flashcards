# even — Production 2

## Dados da nota
- **Prompt:** Diga em inglês: “Este número é par.”
- **Context:** Agora use o sentido matemático de “par”.
- **Answer:** This number is <b>even</b>.
- **PossibleAnswers:** It is an <b>even</b> number.
- **Focus:** even
- **HowToUse:** Como adjetivo, <b>even</b> descreve um número divisível por dois.
- **Example:** Eight is an <b>even</b> number.
- **ExampleTranslation:** Oito é um número par.
- **CommonMistakes:** Não use <b>even</b> para “igual” em todos os contextos; para igualdade, use <b>equal</b> ou <b>the same</b>.
- **Source:** flashcards/Vocabulary/even.md
