- **Prompt:** Como você diria “Se alguém ligar, anote o recado” em inglês?
- **Context:** Você está deixando instruções para uma pessoa que ficará no escritório.
- **Answer:** If **anyone** calls, take a message.
- **PossibleAnswers:** If **anybody** calls, take a message. — alternativa igualmente natural
- **Focus:** anyone
- **HowToUse:** Use **anyone** em condições para se referir a uma pessoa não especificada que possa fazer algo.
- **Example:** Let me know if **anyone** has questions.
- **ExampleTranslation:** Avise-me se alguém tiver perguntas.
- **CommonMistakes:** Não use “someone” quando a ideia for aberta ou incerta em uma condição; nesse contexto, **anyone** é a escolha mais natural.
